    笔记开头与站内展示

    文件从 --- 开始，到下一个 --- 为止是 YAML。title 必填，生成页面最上方的文章标题。description 是摘要，order 数字越小越靠前，date 采用 YYYY-MM-DD 格式并参与首页「最近更新」，tags 会显示在页首并能搜索。draft: true 从公开页面、目录和搜索中隐藏笔记，example: true 显示「示例文章」标签。

    YAML
    ---
title: Markdown 语法与网页效果
description: 可在写笔记时查阅的语法示例。
order: 30
date: "2026-11-21"
tags: ["Markdown", "排版"]
draft: false
example: false
---

    标题、段落与分隔线

    标题层级

    # 到 ###### 依次表示一到六级标题，井号后留空格。正文通常从 ## 开始。右侧「本页目录」自动收录二、三级标题，其他级别正常显示在正文里。用单独一行 === 或 --- 给上一行加下划线，也能生成一级或二级标题。

## 二级标题

    分段、换行和分隔

    空一行开始新段。普通换行仍属于同一段。行末加反斜杠或两个空格，才会在段内强制换行。分隔线上下留空行，可用 ---、*** 或 ___。

    markdown
    这两行在
同一个段落里。

这一行末尾加反斜杠。\
下一句另起一行，但仍在同一段。

---

    加粗、斜体、删除线与转义

    星号和下划线都可以写强调。行内代码保留原字符，适合文件名、命令和变量名。反斜杠让语法符号按字面显示。常用 HTML 字符实体也可以直接写在正文里。

    markdown
    **加粗**、__也加粗__、*斜体*、_也斜体_、***粗斜体***、~~删除线~~
行内代码 `npm run build`
转义 \*保留星号\*、\$20、\#保留井号
字符实体 &lt;、&gt;、&amp;、&copy;
自动标点 "Markdown" -- plain text...

    加粗、也加粗、斜体、也斜体、粗斜体、删除线

    行内代码 npm run build

    转义 *保留星号*、$20、#保留井号

    字符实体 <、>、&、©

    普通英文引号、双连字符和三个句点会自动排成弯引号、破折号和省略号，比如 “Markdown” — plain text… 。在行内代码里写 "Markdown" -- plain text... 可以保留原样。

    表格与脚注

    表格

    第一行是表头，第二行写分隔符。单元格以 | 分开。单元格里可以放加粗、代码、链接或行内公式。显示竖线时写 \|。Markdown 的 :---、:---:、---: 分别标记左对齐、居中和右对齐，本站目前统一左对齐。

    markdown
    | 内容 | 例子 | 数值 |
| :--- | :---: | ---: |
| **权重** | `w` | 3 |
| 绝对值 | \|x\| | $x^2$ |
    内容 例子 数值
    权重 w 3
    绝对值 |x| x2x^2x2

    脚注

    正文用 [^标识] 引用，在另一行用 [^标识]: 内容 定义。脚注自动汇集在文末，点击编号跳到脚注，从脚注也可返回正文。多段脚注的后续段落缩进四个空格。

    markdown
    这里有一个补充说明。[^source]

[^source]: 在这里写来源或补充解释。

    这里有一个补充说明。1

    代码块与复制

    用三个反引号或波浪号包住代码。围栏后写语言名，例如 python、javascript、sql、bash 或 yaml，会按语法上色。不写语言名则显示为纯文本。段前空一行，再把每行缩进四个空格，也可以写纯文本代码块。需要在代码块内展示三个反引号时，把外层围栏加长。

    markdown
    ```python
weights = [2, 3, 5]
print(sum(weights))
```

~~~

    数学公式

    单个 $ 用于行内公式。块级公式在公式两侧各用一行 $$，可以用 aligned 在等号处对齐。也可以用名为 math 的代码围栏写块级公式。渲染由 KaTeX 完成，直接写它支持的 LaTeX 数学命令。

    行内公式 $x^2 + y^2 = r^2$。

    原生 HTML 与 MDX

    标记、上下标、键帽与折叠

    普通 .md 可以用原生 HTML 补充排版。例如用 <mark> 高亮、用 <sub> 和 <sup> 写文字上下标、用 <kbd> 标记按键、用 <abbr> 显示缩写说明。HTML 注释 <!-- 注释 --> 在正文中不显示。只留在本地的编辑备注可以写进开头 YAML 的 # 注释。折叠区域用 <details>，若里面写 Markdown，在 </summary> 之后和 </details> 之前各留一行空白。

    markdown
    <mark>高亮重点</mark>、<u>下划线</u>、H<sub>2</sub>O、m<sup>2</sup>、
<kbd>Ctrl</kbd> + <kbd>K</kbd>、<abbr title="普通最小二乘法">OLS</abbr>。
