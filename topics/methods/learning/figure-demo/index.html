    把图加到自己的笔记

    静态图：从 TikZ 导出 SVG

    在章节下为这篇笔记建独立目录，将正文保存为 index.md 或 index.mdx。在同目录下建立 assets/，每组图用一个子目录收纳 SVG、绘图源码和交互组件。共用的导出脚本和样式放在 assets/shared/。用 Python 绘图时，把 .py 和重新绘图所需的数据放在该图的子目录。以下命令在项目根目录运行，需要 TeX Live（XeLaTeX 和 TikZ）、Poppler 和 Python 3。

    Bash
    cd src/content/methods/learning/figure-demo/assets
bash shared/export-tikz.sh is-lm-ad/is-lm-ad.tex is-lm-ad/is-lm-ad-stacked.tex

    脚本将 TikZ 编译成单页 PDF，再用 pdftocairo 把 SVG 导出到各自的 .tex 旁，并加入深浅模式样式。第二个文件从同一份绘图源码生成窄屏版。复用这套导出样式时，把 export-tikz.sh 和 figure-style.sty 放在新笔记的 assets/shared/ 里。导出后，可在 .md 或 .mdx 正文里用 Markdown 引用。

    markdown
    ![IS–LM 与 AD 联动示意](./assets/is-lm-ad/is-lm-ad.svg)

    交互图：在 MDX 中导入组件

    用 .mdx 保存笔记，保留原来的 YAML。复用 IS–LM–AD 时，将 is-lm-ad/ 和 shared/ 复制到新笔记的 assets/，再用相对路径导入组件。

    mdx
    import IsLmAd from './assets/is-lm-ad/IsLmAd.astro'

<IsLmAd initialPrice={1} minPrice={0.5} maxPrice={2} step={0.05} />

    initialPrice 设定初始价格，minPrice 和 maxPrice 设定范围，step 设定每次微调的幅度。移动笔记时可直接移动整个笔记目录。把 index.md 改成 index.mdx 时，笔记网址保持不变。

    给静态图加图注

    在 MDX 中用 figure 包裹图片，并在 figcaption 中写图注。导入 shared/figure.css 可复用示例的图块样式。

    mdx
    import './assets/shared/figure.css'

<figure className="demo-figure demo-static">

</figure>
